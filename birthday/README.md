# День рождения Даши

Локальный сайт без установки зависимостей и внешних ресурсов.

## Запуск

Из папки `birthday`:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открой `http://127.0.0.1:8000` в браузере на своём компьютере. Также можно открыть `index.html` напрямую. Прогресс сохраняется в этом браузере; перед вручением нажми «Начать заново».

## Подготовка сюрпризов

1. В шкафу с бельём спрячь свой стих. Добавь строку «Секретное слово: нежность».
2. На верхней полке размести букет и записку со строкой «Секретное слово: цветы».
3. Подготовь сертификат Wildberries для вручения в финале.

Все тексты, вопросы, ответы и кодовые слова — в `config.js`. Вопросы уже персонализированы; поздравление можно заменить своим перед праздником. В первом вопросе требуется вариант Г: другие ответы дают мягкую подсказку. Вопрос про танцы принимает любой ответ. В вопросе №3 про праздничные привилегии правильный вариант Г; остальные дают разные подсказки и позволяют попробовать снова. Вопрос про планы принимает любой ответ, с отдельной реакцией на каждый вариант. Последний вопрос, про любовь, показывает шуточный вердикт после любого ответа. Коды из записок обязательны. На линии прогресса можно вернуться к открытым этапам; будущие заблокированы.

Можно добавить файл сертификата и музыку в папку `assets`, затем указать относительные пути в `certificateFile` и `musicFile`. Не публикуй сертификат: он может содержать код погашения. Без файла финал предлагает вручить его лично. Без музыки кнопка звука скрыта.

Секретные слова находятся в исходном коде: это игровой механизм, а не защита данных. Для репетиции пройди весь маршрут, проверь записки и расположение подарков, затем сбрось прогресс.

Маршрут: старт → настолки → тайник №1 → танцы → праздничные привилегии → планы → тайник №2 → любовь → поздравление → подарок. После обновления до пяти вопросов репетиция начинается заново, чтобы прежние сохранённые этапы не перепутались.

## Праздничные эффекты

Кнопка «На весь экран» в шапке скрывает интерфейс браузера, если браузер поддерживает этот режим. Выход — кнопкой или Escape. Музыка по-прежнему необязательна.

После верного кода появляется открытый замок: нажми «Да, продолжаем», чтобы идти дальше. В финале нажми «Ладно, открываем» — подарок распакуется. Открытый подарок сохраняется вместе с прогрессом; для повторной распаковки нажми «Начать заново».

Для фото на экране личного поздравления положи снимок в `birthday/assets/us.jpg` и укажи `photoFile: 'assets/us.jpg'` в `config.js`. Подпись для доступности меняется в `photoAlt`. Если путь пустой или файл недоступен, пустая рамка не показывается. Личный снимок можно хранить только на своём компьютере, без отправки в GitHub.
